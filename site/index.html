Core protocol

Not just another chain.
A new kind of interaction.

Voxian sits where privacy, programmable payments and AI agents meet. Everything below is implemented in the repo and running on the devnet.

◈

Zero-knowledge privacy

Confidential notes with Pedersen commitments, zero-knowledge range proofs, balance proofs and stealth one-time addresses. Amounts and recipients stay hidden on-chain.

Shield · Send · Unshield
↗

x402 machine payments

APIs answer HTTP 402 Payment Required. An agent can pay with a gasless signed authorization, or privately with a shielded note that only the service's facilitator can verify.

exact · zk-shielded
⌘

Autonomous agents

A budgeted agent finds paid services, plans from a goal and pays per request with no human approving each step. It switches to private payments when it holds shielded funds.

Discover · Plan · Pay
⧗

Proof of History

A sequential SHA-256 clock. Every transaction is mixed into the chain, giving verifiable ordering, and a leader can only claim a later slot by doing the hashing.

Slots · Epochs · Leader schedule
◆

Open Proof of Stake

Register a validator or delegate VOX. Block rewards are shared after commission, and validators sign with a crash-safe signing log so they can't double-sign by accident.

Stake · Delegate · Unbond
⛓

BFT finality & slashing

Tendermint-style prevote and precommit finality. The chain survives one validator in four going down. Double-signing is detected automatically: the offender is slashed, the VOX burned and the validator jailed.

Final in one round
The bigger picture

When software can pay for what it needs.

AI is moving from answering questions to taking action. That shift needs infrastructure that lets agents pay for services, privately and without asking permission at every step.

The next interface may not be a screen. It may be an agent, making things happen in the background.

01

Request

An agent calls a paid API: a price oracle, AI summarizer or data feed.

02

402 Payment Required

The service answers with its price and two payment options: exact and zk-shielded.

03

Pay privately

The agent builds a shielded payment with zero-knowledge proofs and retries with an X-PAYMENT header.

04

Settle & finalize

The facilitator settles on-chain. The payment is ordered by PoH and becomes final once validators holding more than 2/3 of the stake sign.

Run it yourself

One command.
No dependencies.

Pure JavaScript on Node 20+, with no packages to install. Run a single node, a four-validator cluster, or an AI agent that pays for data over x402. Or skip all of it and open the in-browser demo.

$ git clone https://github.com/neroiq-47/Voxian-Chain
$ cd Voxian-Chain
$ npm start # full node + web app → localhost:8402
$ npm run cluster # 4 validators, BFT finality
$ npm run agent # an AI agent pays via x402
$ npm test # crypto, ZK, consensus, x402

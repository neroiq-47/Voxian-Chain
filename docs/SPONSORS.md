# Sponsoring Voxian

Voxian is funded through **[GitHub Sponsors](https://github.com/sponsors/neroiq-47)**. The tiers run from budget-friendly individual support up to enterprise partnerships. Every tier funds the same roadmap: independent security reviews, a public testnet, and development of the ZK + x402 + AI-agent stack.

> **Sponsorship is a donation to open-source development.** It is not an investment, equity or a token sale. It does not buy, reserve or promise any VOX: VOX is a proposed token and the devnet tokens have no value. Benefits are limited to the recognition and services listed below.

## Monthly tiers

| Tier | Monthly | Who it's for | Benefits |
|---|---:|---|---|
| ☕ **Supporter** | $5 | Anyone who likes the project | Sponsor badge on your GitHub profile · thanks in the monthly update |
| 🛠 **Builder** | $25 | Developers building on Voxian | Everything above · name in the README sponsor list · monthly progress update |
| 🤖 **Agent Pioneer** | $100 | Indie teams and AI-agent builders | Everything above · priority triage of your issues · early access to testnet announcements |
| ⛓️ **Validator Partner** | $500 | Startups and infrastructure operators | Everything above · small logo in the README and web app (planned) · quarterly roadmap call |
| 🏢 **Enterprise** | $2,500 | Companies evaluating private payments and x402 | Everything above · medium logo · 2 hours a month of integration support (x402 facilitator, shielded payments, agent payments) · early access to security-review summaries |
| 🏛 **Enterprise Partner** | $10,000 | Organisations backing the security-review and testnet milestones | Everything above · large logo at the top of the README and web app (planned) · 8 hours a month of integration and architecture support · named credit as a funder of the independent security review · a non-binding seat at a quarterly roadmap review |

**One-time sponsorships** of any amount are welcome too. Enable "custom amounts" in the dashboard so people can give exactly what fits their budget.

Organisations can sponsor from a GitHub organisation account, and can pay by invoice through GitHub where eligible.

## What the money pays for (in order)
1. **Independent security reviews** of the cryptography (range proofs, stealth addresses, signatures) and of consensus (PoH, BFT, slashing). The white paper requires these before any mainnet decision.
2. **Public testnet infrastructure:** validator and seed nodes, the faucet, an explorer, and hosting for the in-browser demo.
3. **Development time** on the roadmap in [`POH_POS_UPGRADE.md`](POH_POS_UPGRADE.md) and the README.

## Setting the tiers up (maintainer checklist)
GitHub Sponsors tiers are configured on GitHub, not in this repository:

1. Go to **github.com/sponsors/neroiq-47/dashboard → Sponsor tiers**.
2. Add the six monthly tiers above, using the exact amounts and benefit text, and publish each one.
3. Under **One-time tiers / custom amounts**, enable custom amounts. You can also suggest a $10 one-time option.
4. In **Profile**, link this file and describe the goal, e.g. "Fund the first independent security review".
5. Optional: add a **sponsorship goal** (for example, monthly sponsors or a dollar target for the security review) so progress shows on the profile.

Only promise benefits you can actually deliver each month. The tiers above are deliberately limited to recognition, communication and bounded support hours.
